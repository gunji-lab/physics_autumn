# Physics Trainer 2（秋学期）

春学期版に合わせた画面と学習フローを持つ、秋学期用トレーナーです。大学Googleアカウント認証、GASによる学習履歴、進捗表示、ダッシュボードを引き継いでいます。

## 画面と問題

- `index.html`: 春学期版と同じ大学Googleログイン版カードを置いたトップ画面。
- `login.html`: 大学アカウントの追加・選択画面。
- `lessons.html`: 認証後の単元一覧。
- `coulomb/`: 「電荷とクーロンの法則」の問題を保管。初回授業中は非表示で、直接開いても単元一覧へ戻ります。
- `electric_field/`: 初回授業中は講義内演習だけを表示し、カードから問題へ直行します。Level 1・2の問題は保管し、直接開いても単元一覧へ戻ります。
- `electric_potential/`: 第4回「電位」の授業内演習（大問4問・小問9問）。
- `common/`: 認証、進捗、問題出題、結果保存に共通の処理。
- `style.css`: 春学期版に合わせた画面デザイン。
- `gas/physics_trainer_2.gs`: 認証、記録、進捗、ダッシュボードと大学アカウント案内画面。

問題とGASの記録先は春学期版から独立しています。既存の秋学期用ステージ名は維持しています。初回授業中、学生の進捗の分母は講義内演習1件です。

## 反映方法

1. GitHub Pages にこのフォルダの変更を公開します。
2. 認証用と記録用のGASに `gas/physics_trainer_2.gs` を反映し、両方のWebアプリを新しいバージョンで再デプロイします。認証用GASの再デプロイで講義内演習1件の進捗表示と新しい画面URLが反映されます。
3. 大学アカウントでログインし、単元一覧から講義内演習へ進めること、結果保存、進捗表示を確認します。

授業中の保存は認証用GASの `saveAuthenticatedResult` を経由して、そのGASに紐づくスプレッドシートへ書き込まれます。保存修正を反映するには、認証用GASのコードを更新し、既存のWebアプリのデプロイを新しいバージョンへ更新してください。反映確認には、教員アカウントで講義内演習を1回終え、結果画面の「学習履歴を保存しました」と保存先ID・Log行番号を確認します。教員ダッシュボードに「講義内演習：演習問題」の欄が出ていなければ、公開中のGASは古いバージョンです。

講義内演習の「演習問題」は電場と力の違いを問う7つの小問です。⑤は電場の強さを数値入力し、向きも選びます。

## 講義内演習の教員向け集計

教員ダッシュボードの先頭に、演習問題の提出者数・提出率と各小問の正答率を表示します。履修者数を教員ダッシュボードの入力欄で一度保存すると、提出率の分母に使われます。履修者数が未設定の間は提出者数のみ表示します。各小問の正答率は学生ごとの最新の提出を集計し、教員・テスト用アカウントは除外します。

## 結果の保存

GAS画面内で解いた結果は、認証済みの親GASへ送って保存完了の応答を受け取ります。失敗時は結果画面に理由と再送ボタンを表示します。教員アカウントの結果画面には保存先シートIDとLog行も表示します。

### 教員アカウントで学生として試す

認証用GASを最新版に再デプロイした後、`gunji@toyo.jp` で認証用URLの末尾に `?view=studentTest` を付けて開くと、`GUNJI_TEST` として学生画面・保存・進捗を試せます。通常の認証用URLでは引き続き教員としてログインできます。テストの回答は `Log` に `GUNJI_TEST` として残り、教員ダッシュボードの集計にも含まれます。テスト画面から「詳しい学習状況を見る」を開くと、`GUNJI_TEST` の進捗を確認できます。

## 記録用シートの初期化

記録用スプレッドシートに紐づくGASエディタで `initializeAutumnSheets` を一度実行すると、`Log`、`Counts`、`QuestionTimes` と各1行目の見出しを作成します。回答行は追加しません。実行ログに出る `spreadsheetId` が、教員アカウントで問題を解いた後の結果画面に出る保存先IDと一致することを確認してください。違う場合は、認証用GASと記録用GASが別のスプレッドシートを参照しています。

# Physics Trainer 2（秋学期）

春学期版の大学Googleアカウント認証とGASによる学習記録を引き継ぐ、後期用の独立したトレーナーです。現在は「電荷とクーロンの法則」と「電場と電気力線」の基礎演習を掲載しています。

## 構成

- `index.html`: ログイン専用のトップ画面。
- `lessons.html`, `style.css`, `trainer.js`: 認証後の問題画面。記録用GASへ回答を送ります。
- `questions.js`: 問題文、選択肢、正解、解説。ここを編集すると問題を差し替えられます。
- `electric_field/`: 電場と電気力線の単元ページ。`lecture.html` は講義内演習の準備ページ、`level1.html` は概念、`level2.html` は計算問題です。問題文は同フォルダの `questions.js` にあります。
- `gas/physics_trainer_2.gs`: 春学期版の認証、回答履歴、進捗、ダッシュボードを継承したGASコード。

## 公開前の設定

1. **秋学期専用の新しいGoogleスプレッドシート**を作成し、そのシートに紐づくApps Scriptへ `gas/physics_trainer_2.gs` を貼り付けます。春学期のシートとスクリプトは変更しません。
2. `NEW_TRAINER_BASE_URL` は `https://gunji-lab.github.io/physics_autumn` に設定済みです。実際の公開URLが違う場合は変更してください。認証後の戻り先を決める設定です。
3. 同じスクリプトからWebアプリのデプロイを**2つ**作成します。認証用は「アクセスしているユーザーとして実行」「大学組織内のみ」。記録用は「自分として実行」「全員」。記録用は公開URLですが、署名付き認証情報がない提出は保存されません。
4. `trainer.js` とトップのリンクには、提供された認証用・記録用の `/exec` URLを設定済みです。学生には公開した `physics_autumn/index.html` を案内します。トップの「大学アカウントでログイン」から認証用GASへ移動すると、認証後はそのGAS画面内に `lessons.html` の問題一覧が表示されます。
5. 大学アカウントで開き、3問に回答して、専用シートの `Log`、`Counts`、`QuestionTimes` に1回分の記録が入り、進捗画面に反映されることを確認します。

大学のメールアドレス全体は学習シートに保存しません。GASが大学Googleアカウントを確認し、学籍番号だけを記録します。テスト時は大学アカウントでの認証とGoogleスプレッドシートへの書き込みを実際に確認してください。

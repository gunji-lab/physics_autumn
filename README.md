# Physics Trainer 2（秋学期）

春学期版に合わせた画面と学習フローを持つ、秋学期用トレーナーです。大学Googleアカウント認証、GASによる学習履歴、進捗表示、ダッシュボードを引き継いでいます。

## 画面と問題

- `index.html`: 春学期版と同じ大学Googleログイン版カードを置いたトップ画面。
- `login.html`: 大学アカウントの追加・選択画面。
- `lessons.html`: 認証後の単元一覧。
- `coulomb/`: 「電荷とクーロンの法則」の単元とStage 1。問題は `questions.js`。
- `electric_field/`: 「電場と電気力線」の単元、講義内演習①、Level 1・2。問題は `electric_field/questions.js`。
- `common/`: 認証、進捗、問題出題、結果保存に共通の処理。
- `style.css`: 春学期版に合わせた画面デザイン。
- `gas/physics_trainer_2.gs`: 認証、記録、進捗、ダッシュボードと大学アカウント案内画面。

問題とGASの記録先は春学期版から独立しています。既存の秋学期用ステージ名は維持しているため、学習履歴も継続して表示できます。

## 反映方法

1. GitHub Pages にこのフォルダの変更を公開します。
2. 認証用と記録用のGASに `gas/physics_trainer_2.gs` を反映し、**認証用のWebアプリを新しいバージョンで再デプロイ**します。GASから表示するアカウント案内画面と学生・教員ダッシュボードの秋学期用集計は、GitHub側の更新だけでは変わりません。
3. 大学アカウントでログインし、単元一覧、Stage 1、結果保存、進捗表示を確認します。

講義内演習の「演習問題」は電場と力の違いを問う7つの小問です。⑤は電場の強さを数値入力し、向きも選びます。

## 講義内演習の教員向け集計

教員ダッシュボードの先頭に、演習問題の提出者数・提出率と各小問の正答率を表示します。履修者数を教員ダッシュボードの入力欄で一度保存すると、提出率の分母に使われます。履修者数が未設定の間は提出者数のみ表示します。各小問の正答率は学生ごとの最新の提出を集計し、教員・テスト用アカウントは除外します。

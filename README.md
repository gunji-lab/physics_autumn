# Physics Trainer 2（秋学期）

春学期版の大学Googleアカウント認証とGASによる学習記録を引き継ぐ、後期用の独立したトレーナーです。現段階の問題は「電荷とクーロンの法則」3問だけです。ほかの単元は講義に合わせて一緒に作成します。

## 構成

- `index.html`, `style.css`, `trainer.js`: 学生向け画面。GASの `?view=app` から開きます。
- `questions.js`: 問題文、選択肢、正解、解説。ここを編集すると問題を差し替えられます。
- `gas/physics_trainer_2.gs`: 春学期版の認証、回答履歴、進捗、ダッシュボードを継承したGASコード。

## 公開前の設定

1. **秋学期専用の新しいGoogleスプレッドシート**を作成し、そのシートに紐づくApps Scriptへ `gas/physics_trainer_2.gs` を貼り付けます。春学期のシートとスクリプトは変更しません。
2. `NEW_TRAINER_BASE_URL` を、公開した `physics_autumn` のURL（末尾スラッシュなし）に設定します。例：`https://gunji-lab.github.io/physics_autumn`。
3. Webアプリとして新しいデプロイを作成します。「実行するユーザー」は**アクセスしているユーザー**、「アクセスできるユーザー」は**大学組織内のユーザー**にします。学生には静的サイトのURLではなく、このGASの `?view=app` URLを案内します。
4. 大学アカウントで開き、3問に回答して、専用シートの `Log`、`Counts`、`QuestionTimes` に1回分の記録が入り、進捗画面に反映されることを確認します。

大学のメールアドレス全体は学習シートに保存しません。GASが大学Googleアカウントを確認し、学籍番号だけを記録します。テスト時は大学アカウントでの認証とGoogleスプレッドシートへの書き込みを実際に確認してください。
